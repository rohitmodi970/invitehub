# InviteHub.in - Digital Invitation Platform

## Project Overview

Build a web application called InviteHub.in where users can create beautiful digital invitation cards in minutes.

Initially, the platform will focus on Wedding Invitation Cards and later expand to Birthday, Engagement, Baby Shower, Housewarming, Anniversary, and Corporate Event invitations.

The goal is to allow users to select a template, fill in event details, preview the card, and download or share it online.

---

## Core Features (MVP)

### 1. Landing Page

- Modern and elegant design
- Hero section
- Featured templates
- How it works section
- Testimonials section
- Pricing section
- FAQ section

**CTA:** "Create Your Invitation Card"

---

### 2. Template Gallery

Users can browse invitation templates.

**Categories:**
- Wedding
- Royal Wedding
- Floral Wedding
- Traditional Indian Wedding
- Modern Wedding

**Each template should display:**
- Preview image
- Template name
- Use Template button

---

### 3. Invitation Creation Form

**Collect information such as:**
- Bride Name
- Groom Name
- Wedding Date
- Wedding Time
- Venue Name
- Venue Address
- Contact Number
- Family Details
- Additional Message
- RSVP Details

**Optional:**
- Couple Photo Upload
- Family Photo Upload

---

### 4. Live Preview

As users fill details, the invitation preview should update in real-time.

**Features:**
- Responsive preview
- Mobile view
- Desktop view

---

### 5. Invitation Page Generation

Generate a unique invitation page:

**Example:** `invitehub.in/i/rohit-shraddha`

**The page should contain:**
- Invitation card
- Couple photos
- Wedding details
- Google Maps location
- Countdown timer
- RSVP button

This page should be shareable through WhatsApp.

---

### 6. Download Options

Generate:
- PNG
- JPG
- PDF

Downloads should be watermark protected for free users.

**Example watermark:** "Created with InviteHub.in"

---
