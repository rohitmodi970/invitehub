# Template Image Prompts for ChatGPT (DALL·E)

Use these prompts to generate final preview images. Save each file to:

`public/images/templates/<filename>`

## Global settings (use for every image)

- **Aspect ratio:** 3:4 portrait (900×1200 px recommended)
- **Style:** Flat mockup of a digital invitation card — not a photo of a printed card on a table unless noted
- **No real names, phone numbers, or addresses** — use placeholder text like "Priya & Rahul", "15 February 2027", "Taj Palace, New Delhi"
- **No watermarks, logos, or "InviteHub" text**
- **Clean, high-resolution, suitable for website thumbnail and Open Graph preview**

For `-thumb.png` files: generate the same design cropped tighter or at 450×600 px.
